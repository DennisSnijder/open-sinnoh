# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue or on Discord. Use GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**
([direct link](https://github.com/DennisSnijder/open-sinnoh/security/advisories/new)).

Include what you found, how to reproduce it, and what an attacker could do with it. You will get an answer
as soon as the maintainers can look at it, and credit in the fix if you want it.

## Scope

In scope: the game at play.opensinnoh.com, the website at opensinnoh.com, and the code in this repository.
Examples: a way for a crafted save, pack, mod or gift code to run script in the page or reach another
origin, or a way for the error reports or analytics to send more than [docs/privacy.md](docs/privacy.md)
describes.

Out of scope: bugs that need a modified local build, and issues in third-party services themselves.

Never attach a ROM, ROM dumps or imported game data to a report.
