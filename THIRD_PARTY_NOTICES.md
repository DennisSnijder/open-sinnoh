# Third-party notices

The game (play.opensinnoh.com) bundles the third-party software and fonts below; the website
(opensinnoh.com) bundles only the fonts. Each build ships this file as `third-party-notices.txt`.
Development-only tools (Vite, Vitest, Playwright, TypeScript, ESLint and the rest of `devDependencies`)
are not shipped and are not listed. OpenSinnoh's own code is under the licence in [LICENSE](LICENSE).

No part of any Pokémon game is included: the game data comes from the player's own ROM, imported in
their browser.
